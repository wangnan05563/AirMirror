## 07 风险与决策

1. **M2 是全局瓶颈但已推进一格**：T06111 安装包已闭环，T06112 TrustRegistry 成为下一项；T06115 仍是 M3 音频前置，首次投屏/摄像头/Win11 现场项必须补测。
2. **M1 实现链长**：T06102~T06107 共 6 项依赖串联；主题/布局/空态/两步交互任何一环返工都会拖到 M1 回归。
3. **性能指标尚无可信真机数据**：SLO 文档已定义，T06121 前不能对外宣称“首帧 3 秒/延迟 200ms 达标”。
4. **release 包与 debug 包不可直接比体积**：001 debug 6.60MB、002 release 5.34MB；体积结论必须同构建类型、同签名口径。
5. **物理 AP 隔离**：T06122 只有判决单测，T06129 必须在真实路由器开关 AP 隔离复验。
6. **mDNS 现场证据缺口**：T06109 只有协议与本机链路证据，真实 Wi‑Fi 首台 ≤3s 需在 T06128 用 Android 接收端实测；无组播时只能走手动 IP，不做 UDP 广播降级。
7. **PC 摄像头依赖 BridJ 原生库**：webcam-capture 在部分 Windows 驱动/安全软件下可能打不开；T06110 已提供截图导入降级，但“摄像头真机扫码”必须留在 T06115 补测，不能按协议测试冒充。
8. **PC 安装包仍有三项现场缺口**：首投 ≤2min 只验证了安装阶段 53.9s；同网发现 ≤3s 与 Win11 未实测；FFmpeg 未打进包，当前走 JCodec 兜底，需后续传 `-FfmpegDir` 重打包。
